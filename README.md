# Flik

**Write slides in Markdown. Present them in your browser.**

Flik is a Linux tool that lets you build a deck in your favorite editor. Save to see changes live, style your slides with themes and layouts, and add images using standard Markdown.

## Try the demo

With a current stable Rust toolchain, run:

```sh
cargo run --locked -- examples/demo.md
```

Press **F** to present full-screen and use **← / →** to move between slides. Click **Export PDF** to save the deck through the browser’s print dialog.
